# Dataset Guide

Datasets used in this project are **not committed** to this repository due to their large size and third-party licenses. This document explains how to obtain and organize them.

## Overview

| Dataset | Role | Families | Samples | Source |
|---------|------|----------|---------|--------|
| UTL_DGA22 | DGA training | 76 | 152,000 | GitHub (Tuan et al. 2023) |
| Tranco Top 1M | Benign training | — | 152,000 | tranco-list.eu |
| UMUDGA | External evaluation | 50 | 100,000 | Mendeley (Zago et al. 2020) |
| Netlab360 | External evaluation | 43 | 50,013 | GitHub (Qihoo 360) |
| DGArchive | External evaluation | 79 | 122,592 | Fraunhofer FKIE |

Total external evaluation: **124 unique DGA families, 272,605 samples**.

## 1. UTL_DGA22 (training DGA set)

- **Source**: Tuan et al. (2023) — "UTL_DGA22 - a dataset for DGA botnet detection and classification", Computer Networks
- **DOI**: 10.1016/j.comnet.2022.109508
- **Download**:

```bash
git clone https://github.com/tongtuan92/UTL_DGA22-Dataset.git data/raw/UTL_DGA22
```

- **Expected structure**:

```
data/raw/UTL_DGA22/
└── DGA_Botnets_Domains/
    ├── bamital.txt
    ├── banjori.txt
    ├── ... (76 family files)
    └── zloader.txt
```

Each file contains one domain per line, approximately 2,000 domains per family.

## 2. Tranco Top 1M (benign training set)

- **Source**: Tranco — a research-oriented top sites ranking (combines Alexa, Majestic, Umbrella, Cisco)
- **URL**: https://tranco-list.eu/
- **Reference list used in this project**: https://tranco-list.eu/list/QW4P4/1000000
- **Download**:

```bash
# Direct download of the specific list used
curl -o data/raw/tranco_top_1m.csv https://tranco-list.eu/download/QW4P4/full
```

- **Expected location**: `data/raw/tranco_top_1m.csv`
- **Format**: CSV with columns `rank, domain` (first 152,000 rows after deduplication)

### Note on benign source

Tranco Top 1M (list ID `QW4P4`) is used instead of the deprecated Alexa Top 1M. Tranco aggregates rankings from Alexa, Majestic, Umbrella, and Cisco, providing a research-stable permalink that remains reproducible.

Reference: Le Pochat et al. (2019). "Tranco: A Research-Oriented Top Sites Ranking Hardened Against Manipulation", NDSS.

## 3. UMUDGA (external evaluation #1)

- **Source**: Zago, Gil Pérez, Martínez Pérez — "UMUDGA – University of Murcia Domain Generation Algorithm Dataset"
- **DOI**: 10.17632/y8ph45msv8.1
- **Download**: https://data.mendeley.com/datasets/y8ph45msv8/1
- **Expected structure**:

```
data/raw/UMUDGA/
├── bamital/
│   └── bamital.txt
├── banjori/
├── ... (50 family folders)
└── zloader/
```

Each family folder contains one `<family>.txt` file with ~2,000 domains.

## 4. Netlab360 (external evaluation #2)

- **Primary source**: Qihoo 360 Netlab
- **Download options** (any of the following):

```bash
# Option A: Qihoo 360 official GitHub mirror
git clone https://github.com/360netlab/dga.git data/raw/Netlab360_raw

# Option B: Official data portal
# Browse to: https://data.netlab.360.com/dga/ (daily updated feeds)

# Option C: Cleaned community mirror (recommended)
git clone https://github.com/chrmor/DGA_domains_dataset.git data/raw/Netlab360_mirror
```

- **Expected structure after preprocessing**:

```
data/raw/Netlab360/
├── bamital.txt
├── banjori.txt
├── ... (43 family files)
└── wauchos.txt
```

Netlab360 publishes `dga.txt` with family as a column. Split into per-family files, or use the `chrmor/DGA_domains_dataset` mirror which already provides family-separated files.

## 5. DGArchive (external evaluation #3)

- **Source**: Fraunhofer FKIE
- **URL**: https://dgarchive.caad.fkie.fraunhofer.de/
- **Access**: Academic access required
- **Request procedure**:
  1. Email `dgarchive@fkie.fraunhofer.de` with institutional affiliation
  2. Specify research purpose (DGA detection benchmarking)
  3. Receive access credentials within 1-2 weeks
- **Expected structure**:

```
data/raw/DGArchive/
├── bamital.csv
├── banjori.csv
├── ... (79 family files)
└── zloader.csv
```

Each file contains at minimum a `domain` column.

## 8. Preprocessing

Run `splitDataUTL.py` to produce DataNew:

```bash
python splitDataUTL.py
```

This script:
1. Loads UTL_DGA22 (152,000 DGA domains)
2. Loads Tranco Top 1M, extracts first 152,000 benign domains
3. Deduplicates across both sources
4. Shuffles with fixed seed (42)
5. Splits 70/15/15 into train/val/test
6. Writes `DataNew/train.csv`, `DataNew/val.csv`, `DataNew/test.csv`

**All subsequent experiments read from these fixed files**, ensuring no test-set leakage.

## 10. Troubleshooting

### DGArchive access delayed

If DGArchive access is pending, you can still reproduce most results. External evaluation on UMUDGA + Netlab360 alone covers 93 families and reflects the main generalization conclusions.

### Tranco list ID differs

List ID `QW4P4` is a specific snapshot used in our experiments (stable permalink). Current date-based lists at tranco-list.eu may differ. Always use the permalink to ensure reproducibility.

### Netlab360 updates

Netlab360 continuously updates its feeds. The specific commit/snapshot used for this project is documented in the GitHub Issues (available on request).

### UTL_DGA22 repo structure

The `tongtuan92/UTL_DGA22-Dataset` GitHub repository may have slightly different naming conventions than our scripts expect. The expected folder name is `DGA_Botnets_Domains/`. If the repo uses a different name, rename or symlink accordingly.
